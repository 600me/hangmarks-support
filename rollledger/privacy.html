Privacy policy

Effective date: 7 October 2026. Applies to RollLedger 1.0 for iPhone and iPad.

Data in the app

RollLedger does not collect or transmit personal data to its developer. It contains no advertising, analytics, tracking, account system, third-party SDK or developer-operated server. The app makes no network requests.

Project names, wall measurements, roll settings and checked cuts are stored locally on your device. You can delete saved projects in the app. Removing the app can remove its data. Device backups are controlled by Apple and your device settings; the developer cannot access them.

PDF export

When you choose to export, the native share sheet sends a PDF only to the destination you select. The sheet contains project names, measurements, matching settings and cut progress. The chosen service handles the file under its own privacy practices.

Website and support

This site uses GitHub Pages without advertising, analytics scripts or application cookies. GitHub may process technical data such as IP addresses to provide its service under its privacy statement.

GitHub Issues support reports are public and contain your GitHub profile and whatever you post. The developer reads reports to provide support. Avoid private information; you can edit a report or request removal in the same issue.

For questions, use RollLedger support. Changes to the app’s data practices will be reflected in this policy before or alongside the change.

隐私政策

生效日期：2026年10月7日，适用于 RollLedger 1.0。

应用不向开发者收集或传输个人数据，不含广告、统计、跟踪、账号系统、第三方 SDK 或开发者服务器，不发起网络请求。项目名称、墙面尺寸、纸卷设置和已裁勾选保存在本机。可删除已保存项目；卸载应用可能移除数据。系统备份由 Apple 和设备设置控制，开发者无法访问。

主动导出 PDF 时，系统分享面板仅向你选择的位置发送施工单，内容包含项目名称、尺寸、对花设置及裁切进度。接收服务按其自身隐私规则处理。

网站由 GitHub Pages 托管，无广告、统计脚本或应用 Cookie。GitHub可能处理 IP 等技术数据。GitHub Issues 反馈内容公开，包含你的 GitHub 资料和自愿提交的内容；请勿提交私人信息。可编辑自己的反馈或在原反馈中请求移除。

隐私问题可通过上方客服入口提出。数据处理方式变化时，本政策会在变化前或同时更新。
